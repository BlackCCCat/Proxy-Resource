| 目录 | 内容 |
| --- | --- |
| [`Surge/`](Surge/) | Surge 模块、配套脚本及源码补丁 |
| `Loon/` | 计划收录 Loon 插件 |
| `Egern/` | 计划收录 Egern 模块 |
| `Stash/` | 计划收录 Stash 覆写 |
| `Rules/` | 自用规则集仓库：[rule-set](https://github.com/BlackCCCat/rule-set/tree/master) |

目前先收录[哔哩哔哩增强·关键词融合模块](Surge/README.md)。资源主要按个人使用环境维护；安装前请阅读对应目录的说明、上游来源和兼容性提示。
